# UX 감사 평가 반영 — 2026-10-19

브랜치 `codex/ui-workspace-refresh`. 사용자는 감사 문서 평가 후 제시한 개선 방향의 반영을 요청했다. `UX_CRITICAL_AUDIT_20261019.md`는 수정하지 않았으며, 원문의 모든 처방을 일괄 채택하지 않았다.

## 반영한 동작

| 지적 | 변경 |
|---|---|
| F01 배선 겹침 | 확정 회로의 다른 net 선분이 같은 선상에서 양의 길이로 겹치면 `WIRE_OVERLAP` 도면 경고, 주황 표시, 위치 확인 제공. 수평/수직 교차와 끝점 접촉, 같은 net 중복은 제외. 계산 오류와 분리 |
| 연결망 판독 | 선택 배선과 hover 대상의 같은 net 배선 전체에 배경 강조. 선택 집합은 그대로이며 삭제·Undo 의미론 유지 |
| F02 미저장 | 헤더에 새로고침 시 손실 명시. 편집 이력 또는 프로젝트명 변경 시 beforeunload 경고. Undo로 초기 상태에 돌아오면 경고 해제 |
| F03/F04 Inspector | 전역 설정 카드·개발자 enum·중복 통계 제거. 선택이 있을 때만 편집 명령 표시. 고급 배선 경로 도구는 접힌 섹션. 기존 Properties 유지 |
| F05 출력 위치 | 입력/출력/회로 진단을 하단 도크 세 열로 분리. 시뮬레이션 활성화 시 도크 펼침. 각 열은 독립 스크롤하며 Inspector 길이에 영향받지 않음 |
| F06 값 가독성 | I/O 본체 50%와 핀 ±40 유지. 값은 100%에서 10px, 낮은 배율에서 화면 최소 9px이며 본체 아래 표시. 핀 이름은 9px, 100% 이상에서 노출. 최대 800% 유지 |
| F07 표시 이름 | ID별 세션 번호 레지스트리를 공유. 도면/트리/Inspector/입출력 목록에서 같은 이름 사용. 삭제·Undo로 생존 객체 재번호화하지 않음. 핀 I0…/O, net N1… |
| F09/F12 안내 | 기존 Shift 연속 배치를 안내. 도움말 기본 접힘, 개발자 메모 제거. 빠른 검색 버튼에 목적과 키 힌트 구분 |
| F11 상태바 | 중복 대기 문구·입력 프로필·단축키 목록 제거. 일반 메시지는 5초 후 소거, 실패는 유지. 같은 성공 메시지가 재발해도 다시 표시 |
| F14 작은 화면 | Inspector가 보기 도구와 분석 도크를 가리지 않도록 경계 계산. 1024px 미만에서는 두 drawer를 동시에 열지 않음 |

`wireOverlaps`는 선 방향·좌표별로 묶고 구간을 정렬해 실제 공유 구간을 찾는다. 회로나 계산 엔진에 기록하지 않고 circuit 변경 시에만 다시 계산한다. 자동 레인 분리는 구현하지 않았으므로 겹침 자체가 사라졌다고 주장하지 않는다. 초안 중에는 확정된 겹침 표시를 미리보기 위에 그리지 않는다.

`CircuitLabelRegistry`의 번호는 이 세션의 표시용이다. 모델의 ID·사용자 이름·net 관계는 바꾸지 않고, 삭제된 ID의 번호도 레지스트리에 남겨 Undo 시 같은 번호를 복원한다. 저장 기능은 없으므로 새로 연 세션의 번호 보존은 보장하지 않는다. 계산 엔진이 생성하는 진단 본문은 기존 메시지를 유지한다.

- 단위 테스트: 겹침의 정확한 180 단위 구간, 같은 net/점 접촉/교차 제외, 역방향·음수 좌표·다중 net, 모델 불변, 표시 번호의 삭제/Undo/이름 변경 유지.
- 브라우저: 감사의 2×2 회로에서 도면 경고를 확인하고 전기적 진단 0개와 구분. 연결망 강조 후 단일 삭제 및 Undo. 16입력 Inspector를 선택해도 출력은 화면 안. 50/100/200%에서 값 글자 최소 크기. 미저장 경고 등록/해제. 1024×420에서 Inspector와 줌·출력 hit 영역 분리. 정보 메시지 소거와 실패 메시지 유지.
- 기존 회귀 검증의 편집 횟수 단언은 사용자에게 보이는 `committed edits` 문구 대신 header의 `data-edit-count`를 확인하도록 바꿨다. 기능 검증을 제거하지 않았다. 접힌 고급 경로 도구는 실제로 펼친 뒤 사용한다.
