# Circlith

순차회로 MVP 브랜치 `codex/sequential-simulation`: Clock·DFF, 실행/일시정지·세 가지 Step·초기화, 현재 시각, 관측 파형을 추가했습니다. Clock/DFF가 있는 도면에서 시뮬레이션을 켜면 실행바가 나타납니다. [동작·범위·저장 브랜치 통합 정책](docs/SEQUENTIAL_SIMULATION.md), [구현·검증 결과](review/SEQUENTIAL_IMPLEMENTATION_20261019.md).

2026-10-19 UI 개선 브랜치 `codex/ui-workspace-refresh`: 명령을 묶은 헤더, 줌·그리드·패널 접기 도구, 선택 연동 Inspector, 하단 상태바와 접을 수 있는 진단 도크를 제공합니다. Inspector의 **속성 편집…**은 기존 Properties 창을 열어 같은 Apply/Undo를 사용합니다. 편집/시뮬레이션 모드에 공통 적용하며 [구현·검증 기록](review/UI_WORKSPACE_REFRESH_20261019.md)을 참고하세요.

UX 감사 후속: 다른 연결망의 배선 겹침을 주황색 **도면 표시 경고**로 구분하고 같은 연결망을 강조합니다. 입력·출력·회로 진단은 Inspector와 독립된 하단 도크에 표시합니다. 이름·핀·연결망 표시를 통일하고, 입출력 본체 50%·최대 800%는 유지하면서 값 글자의 화면 최소 크기를 보장합니다. 헤더의 미저장 안내와 이탈 경고는 저장 기능을 대신하지 않습니다. [반영 범위와 검증](review/UI_AUDIT_RESPONSE_20261019.md).

2026-10-19 QA 통합: Input 토글·드래그·팬·포커스, 신호 ID 충돌과 손상 데이터 처리, 입력 수 변경 시 배선 우회·고정 경유점 되짚음, 검증·렌더링 성능과 빌드 출처 검사를 보완했습니다. 잘못된 입력값은 X와 오류 진단으로 처리하고 회로 오류는 출력의 X와 구분합니다. 현재 단위 409개(soak 1개 기본 skip)·브라우저 147개를 검증합니다. [통합 결과](review/QA_INTEGRATION_RESULT_20261019.md).

게이트·입출력 심벌을 **더블클릭 → Properties**에서 이름을 변경할 수 있습니다. AND/OR 계열과 XOR/XNOR는 입력을 2~16개로 조절하고 입력별 반전 버블을 설정합니다. 변경은 Undo/Redo로 복원되며 시뮬레이션에 즉시 반영됩니다. 시뮬레이션을 켜면 선택 모드로 전환하고, 대기 중인 배선 모드에서도 빈 도면 클릭으로 선택을 해제합니다.

회로를 빠르게 그리고, 연결 상태를 이해하고, 실수를 복구할 수 있는 논리회로 시뮬레이션 CAD를 위한 설계 저장소입니다. 가장 중요한 평가 기준은 조작성입니다.

**설계와 구현의 유일한 기준은 [CIRCLITH_MASTER_SPEC.md](docs/CIRCLITH_MASTER_SPEC.md)입니다.** 다른 문서와 충돌하면 Master Spec을 우선합니다.

현재 서비스는 **`main`의 공통 편집기 코드**를 편집 모드와 조합논리 시뮬레이션 모드로 빌드합니다. AND/OR/NOT/XOR/NAND/NOR/XNOR/Input/Output을 옆 부품 패널에서 도면으로 드래그해 배치하고, 접점을 클릭하거나 접점 간 드래그로 배선할 수 있습니다. 선택, 연결 유지 이동·회전, 직각 배선, Delete, Esc, Undo/Redo도 제공합니다. `CURRENT`는 현재 구현 기준이며, `PROVISIONAL`, `EXPERIMENTAL`, `DEFERRED`는 확정되거나 사용성이 검증된 기능을 뜻하지 않습니다.

**`feat/editor-prototype` 브랜치는 조작·제어와 UI/UX 성숙이 우선입니다.** 기존 선택·드래그·배선·회전·화면 이동의 일관성, 피드백, 취소·Undo와 브라우저 충돌을 먼저 다듬습니다. 사용자 요청으로 Delete와 OR/NOT을 추가했으며, 저장·클립보드·추가 부품·시뮬레이션은 별도 단계입니다. 미구현 목록은 즉시 개발할 우선순위가 아닙니다.

**2026-10-18 사용자 요청으로 새 브랜치에서 로드맵 3~4단계를 진행합니다.** 상단 **시뮬레이션**을 켜고 도면의 Input 중앙을 클릭하거나 오른쪽 패널에서 입력을 바꾸면 확정된 회로를 재계산합니다. 출력·배선에 0/1/X/Z를 표시하며 미연결·다중 구동·출력 충돌·조합 피드백을 진단합니다. 입력 변경은 편집 Undo 기록에 포함하지 않습니다. 순차회로·Clock·시간 파형·사용자 테스트벤치는 후속 단계입니다. [시뮬레이션 사용법과 검증](docs/SIMULATION.md)을 참고하세요.

Node.js 22.23.3 이상에서 `npm ci` 후 `npm run dev`로 실행합니다(기본 시뮬레이션 모드). 편집 모드는 `npm run dev -- --mode editor`로 실행합니다. `npm test`, `npx playwright install chromium`, `npm run test:browser`로 검증합니다. 배포용 두 모드 빌드·실행 검증은 [Pages 배포](docs/PAGES_DEPLOYMENT.md)의 명령을 사용합니다. 현재 회로와 시뮬레이션 입력은 메모리에만 유지되며 파일 저장은 후속 단계입니다.

공개 프로토타입: [편집 모드](https://caffentrager.github.io/Circlith/) · [조합논리 시뮬레이션 모드](https://caffentrager.github.io/Circlith/simulation/). 기능은 브랜치에서 개발·검증한 뒤 `main`에 병합합니다. 서비스 배포는 `main`에서만 실행하며, 동일 커밋으로 두 모드를 빌드합니다. 편집기 수정은 두 모드에 함께 반영되고 계산 엔진·계산 UI만 시뮬레이션 모드에서 활성화됩니다. 과거 Phase 브랜치는 기준 버전으로 보존합니다. 배포 시 자산 경로는 각각 `/Circlith/`, `/Circlith/simulation/`입니다.

2026-10-16 QA 후속: 평행 배선 선택, Redo 선택 정리, 고정 경유점 안내와 작은 창 포커스 스크롤을 수정했습니다. 후속 사용자 승인으로 초안 없는 SELECT에서 몸체 직접 클릭은 부품 선택을 우선하고, 핀 직접 클릭·몸체 밖 포획은 유지하도록 수정했습니다. 단위 179개(별도 soak 1개 기본 skip)·브라우저 123개와 빌드가 통과했습니다. [QA 수정·정책 기록](review/QA_FIXES_20261016.md)과 [통합 확장 계획](docs/EDITOR_EXPANSION_SCOPE.md)을 참고하세요.

왼쪽 패널은 **라이브러리 / 도면 트리** 탭입니다. 라이브러리는 논리 게이트·입출력 폴더를 접고 펼치며 검색·클릭·드래그로 배치합니다. 도면 트리는 부품과 연결망별 배선을 표시하며 클릭 선택, Shift+클릭 추가/해제, 더블클릭 화면 맞춤을 지원합니다. 도면 선택과 강조를 공유하고 삭제·Undo도 즉시 반영합니다. 검색·탭 전환·접기만으로 회로나 history를 바꾸지 않으며, 초안 중에는 객체 선택을 비활성화합니다. 서브회로 계층이나 부모·자식 이동 상속은 포함하지 않습니다.

부품과 배선은 클릭으로 선택하고 Shift+클릭으로 추가·해제합니다. 선택 배선은 선분 드래그, 모서리 이동, 우회 구간 추가, 경로 다시 그리기와 가로/세로 우선 정리가 가능합니다. 양 끝 연결은 고정하며 수정 하나마다 Undo로 복구합니다. [배선 편집 사용법과 공식 문서 조사](docs/WIRE_EDITING.md)를 참고하세요.

선 위에서 `W`를 누르거나 배선 도구에서 선을 클릭하면 중간에서 분기합니다. 다른 핀·접속점·선 위에서 클릭/놓기로 연결하며, 분기점 생성과 연결망 합치기는 하나의 Undo로 복구됩니다. 점 없는 교차는 미접속입니다. 겹친 후보는 선택 창에서 구분하고, 명시적인 `이 교차점을 접속` 버튼으로 교차선을 합칠 수 있습니다. 부품 이동으로 생기는 공선 되접힘은 자동 정리하며 기존 접속점은 보존합니다.

설정 → **배선 표시**에서 미접속 교차 점프를 켜고 끄거나 점프할 가로선/세로선을 선택할 수 있습니다. 기본은 켜짐·가로선이며 표시만 바꾸고 회로 연결과 Undo 기록은 유지합니다. 접속점·끝점·모서리 근처와 촘촘한 교차는 생략합니다.

같은 두 접속점 사이에 직선과 우회선이 중복되면 배선을 선택하고 **연결망 중복 정리**를 누릅니다. 제거할 선은 빨간 점선, 남길 경로는 초록색으로 표시하며 Enter 또는 **정리 적용**으로 확정합니다. Esc는 취소, 확정 후 Ctrl+Z는 전체 복구입니다. 중간에 실제 분기가 있는 우회와 다른 net의 교차는 정리하지 않습니다.

선택한 부품/배선은 **Delete**로 삭제합니다. 완성 배선의 사각 꺾임점을 클릭한 뒤 Delete를 누르면 그 점만 제거합니다. 배선 중 클릭 경유점은 번호 있는 사각형으로 표시하며 접속 후보의 클릭 범위도 확대했습니다. [삭제·심벌 사용법과 검증](docs/DELETE_AND_SYMBOLS.md)을 참고하세요.

빈 공간 좌클릭 드래그는 부품·배선 선택박스입니다. 기본 Circlith Modern은 짧은 우클릭 메뉴, Space+좌드래그/가운데 버튼 드래그 화면 이동입니다. 앱의 도면·메뉴·비텍스트 UI에서는 브라우저 기본 우클릭 메뉴를 차단하며 텍스트 입력칸의 편집 메뉴는 유지합니다. 선택박스는 좌→우 전체 포함, 우→좌 교차 선택이며 Shift로 기존 선택에 추가합니다. `설정`에서 배선 정책과 8개 입력 프리셋 선택·navigation 혼합·바인딩 수정·JSON 가져오기/내보내기가 가능합니다. 설정은 브라우저에 저장하며 회로는 저장하지 않습니다.

툴바·편집 버튼 실행 후에는 도면 단축키와 휠을 바로 사용할 수 있습니다. 휠 이동량에 비례해 커서 중심으로 확대하며, 수평 휠은 확대율을 바꾸지 않습니다. 화면 맞춤과 수동 줌은 모두 10–800% 범위를 사용합니다. 일회성 회전이나 드래그 확정이 실패하면 미리보기를 폐기하고 원래 회로와 Undo/Redo 기록을 유지합니다.
