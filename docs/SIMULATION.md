# 조합논리 시뮬레이션

기준: [Master Spec §5.2 및 §23~24](CIRCLITH_MASTER_SPEC.md). 이 문서는 사용법·구현·검증 기록이며 별도 설계 기준을 만들지 않는다.

## 범위

조합논리 기능은 `codex/logic-simulation`에서 개발한 뒤 main의 공통 코드로 통합한다. 순차회로 이전의 조합논리(로드맵 3~4단계)를 구현하며 Vite simulation 모드에서 활성화한다. editor 모드는 같은 7종 게이트·Input/Output·배선 편집 기능을 제공하고 계산 UI를 노출하지 않는다. 저장·복사/붙여넣기, 래치·플립플롭·Clock, 시간 실행·파형·사용자 테스트벤치는 후속 범위다. 실제 IC의 전압·지연·구동 강도를 모델링하지 않는다.

## 사용법

1. Input, 게이트, Output을 배치하고 핀을 연결한다. 분기·교차·연결망 편집은 기존 편집기와 동일하다.
2. 상단 **시뮬레이션**을 켠다. 진행 중인 초안은 취소하고 선택 모드로 전환한다. 입력값은 기본 0이며 출력과 배선에 결과가 나타난다.
3. Input 몸체 중앙을 클릭하면 0/1을 전환한다. 키보드는 중앙 토글에 포커스를 두고 Enter를 사용한다. 핀·상단 이름·몸체 가장자리는 기존 편집 대상으로 유지된다. Space는 도면 이동 기능을 유지한다.
4. 오른쪽 입력 패널에서 0/1/X/Z를 직접 지정할 수 있다. **입력 모두 0**은 모든 입력을 초기화한다.
5. 진단의 **관련 위치 보기**는 관련 부품·배선을 선택하고 화면을 맞춘다.

미확정 배치·배선·이동 초안은 계산에 포함하지 않는다. 초안이나 제스처 진행 중 입력 조작은 비활성화한다. 편집 확정·Undo/Redo마다 확정 회로를 다시 계산한다. 입력 전환은 편집 history를 변경하지 않는다. 입력 상태는 표시를 껐다 켜면 유지되지만, 삭제된 입력은 상태를 제거한다. 삭제 Undo로 복원된 입력은 0이다. 새로고침 시 회로와 입력값은 유지되지 않는다.

## 값과 진단 읽기

게이트·입출력 심벌을 더블클릭하면 **Properties**에서 이름을 변경한다. AND/OR/NAND/NOR/XOR/XNOR는 입력 수 2~16개와 입력별 반전 버블을 설정할 수 있다. NOT은 입력 수를 유지하고 입력 버블을 설정한다. 연결된 입력을 줄일 때는 해당 배선을 먼저 해제한다. 적용은 하나의 Undo이며 취소/Esc는 변경을 버린다. 입력 버블은 게이트가 읽는 값을 반전하고 배선에 표시하는 값은 유지한다. X/Z의 반전 결과는 X, 다중 입력 XOR는 홀수 패리티, XNOR는 짝수 패리티다.

0/1은 확정된 논리값, X는 불명확한 값, Z는 구동 신호가 없는 상태다. 배선에는 값 문자가 표시되며 X는 짧은 점선, Z는 긴 점선이다. 색만으로 구분하지 않는다. Input 몸체에는 사용자가 지정한 구동값, 해당 핀·배선에는 연결망에서 결합된 값이 표시된다. 출력 충돌 때 Input이 0/1이고 배선은 X일 수 있다.

일반 게이트에 Z가 들어오면 X로 취급한다. 단, AND의 0과 OR의 1처럼 결과를 결정하는 입력은 우선한다. 드라이버가 없거나 모두 Z면 연결망은 Z다. 같은 값의 다중 출력도 다중 구동 진단을 내며, 실제 0/1 충돌은 별도 오류다. X 전파만으로 물리적 출력 충돌이라고 진단하지 않는다.

조합 피드백은 순환 게이트 출력을 X로 처리하고 순환 밖은 정상 계산한다. 이 진단은 발진을 측정한 결과가 아니다. 자기 연결 NOT, 교차 결합 게이트 등을 순차회로나 기억 소자로 해석하지 않는다.

## 구현 경계

- `simulation/logic.ts`: 순수 4상태 게이트 계산과 드라이버 결합.
- `simulation/simulator.ts`: 회로 유효성 검사, 연결망·게이트 의존 관계 컴파일, 반복형 강결합 성분 탐색, 위상 순서 계산, 진단. 편집기·React에 의존하지 않는다.
- `ui/App.tsx`: 확정 회로가 바뀔 때 컴파일하고 입력값 변화마다 계산한다. 시뮬레이션 상태는 회로/history와 분리한다.
- `ui/SimulationPanel.tsx`, `renderer/CircuitSvg.tsx`: 입력 조작·출력·배선값·진단 위치 이동.

## 검증

단위 테스트는 7종 게이트의 4상태 진리표, 모든 2-driver 결합, 반가산기 전체 진리표·fanout, 부품 등록 순서 독립성, 400단 NOT 체인, 다중 구동·충돌·Z/X 전파, 자기 피드백·복수 게이트 순환·순환 밖 지배값, 회로 불변성·잘못된 연결/핀 모델 거부를 확인한다.

브라우저 테스트는 도면·패널 입력, 출력·배선값·선 패턴, 입력 변경과 history 분리, 표시 전환, XOR 전체 진리표와 회전, 진단 위치 이동, 배선 Undo/Redo 후 재계산, 초안 중 입력 차단, Enter 조작, 삭제된 입력의 Undo 초기화, 피드백 진단을 확인한다. 진단 위치로 이동한 뒤 기존 배선 꺾임점 선택이 남아 Delete 대상이 바뀌는 회귀도 검사한다. 기존 라이브러리/도면 심벌 비교는 7종 게이트 모두를 종류별로 검사하도록 확장했다.

2026-10-18 최종 검증: 단위 311개 통과·별도 soak 1개 기본 skip, 브라우저 전체 129개 통과(시뮬레이션 6개 포함). TypeScript 검사·프로덕션 빌드 통과. 반가산기 입력 1/1에서 합 0·자리올림 1을 확인하고 1440px 및 1024px 화면을 캡처해 확인했다.

사용성·대규모 회로 성능과 실제 Windows IME 실측을 완료했다는 의미는 아니다.
