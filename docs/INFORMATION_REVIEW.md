# 업로드 전 정보 검토

검토일: 2026-10-13

제공된 Markdown 문서 12개를 대상으로 사용자 홈·로컬 작업 경로, 연락처·이메일·주민등록번호 형태, 비밀번호·토큰·API 키·개인 키 관련 표기와 비공개 정보 가능성을 검토했습니다.

- 사용자 홈과 로컬 작업 디렉터리의 절대 경로를 제거했습니다. 저장소에 있는 문서는 상대 경로로 연결하고, 없는 자료는 파일명과 원본 미포함 표시만 남겼습니다.
- 검토 범위에서 연락처, 이메일, 주민등록번호 형태나 실제 인증 비밀로 보이는 값은 발견하지 못했습니다. 패턴 검사는 모든 민감정보의 부재를 보증하지 않습니다.
- 공개 제품 문서와 공개 참고 프로젝트의 URL은 출처 보존을 위해 유지했습니다.
- 설계 결정과 검토 이력은 유지했습니다. 이전 문서에 보관 상태와 Master Spec 우선 안내를 추가하고, 단축키 종합 문서의 현재 최종안 표현을 과거 권장안으로 정정했습니다.
- Master Spec의 기술 내용과 결정 상태는 변경하지 않았습니다. 통합 당시 자료 제공 범위에 관한 설명은 당시 이력으로 보존했습니다. 이후 저장소 정리 시 확보한 계획·조작·사용성·단축키 원문은 `archive/`에 있으며, Master Spec과의 기술적 재통합은 수행하지 않았습니다.

검토한 원문이 Git 이력에 들어가기 전에 정리를 적용했습니다. 앞으로 자격 증명, 개인 사용성 참가자 기록, 로컬 환경 파일을 커밋하지 않습니다.
