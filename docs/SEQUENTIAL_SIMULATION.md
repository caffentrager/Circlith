# 순차회로·시간 인터페이스 MVP

> 아래 본문은 Clock/DFF 최초 MVP 기록이다. 2026-10-19 후속 요청으로 추가한 7종 순차소자와 게이트 피드백의 현재 동작은 [Master Spec §25.2](CIRCLITH_MASTER_SPEC.md#252-순차소자-확장과-게이트-피드백--2026-10-19), [순차소자 확장](SEQUENTIAL_COMPONENTS.md)을 따른다. 본문의 “추가 FF 후속/피드백 미지원”은 최초 단계 범위에 한정한다.

2026-10-19 사용자 “진행해” 승인으로 Clock/DFF, 실행 제어, 기본 관측 파형을 구현한다.
기준은 UI 인계 커밋 fc6520c이며 브랜치는 codex/sequential-simulation이다.
별도 worktree에서 진행 중인 claude/storage-recovery를 변경하지 않는다.

## 범위

- 공통 편집기 라이브러리에 Clock/DFF. 이동·회전·배선·선택·Properties·Undo/Redo는 기존 편집 경로 사용.
- 시뮬레이션 모드에서 Clock/DFF가 있는 도면에만 시간 실행바와 파형 탭 제공. 기존 조합회로 UI는 유지.
- 실행/일시정지, 다음 이벤트·선택 Clock 다음 상승엣지·한 주기, 초기화, 현재 논리 시각.
- Clock 주기·듀티·초기 레벨과 DFF 동작 엣지·초기 Q 편집. Inspector에서 현재 레벨/Q는 읽기 전용.
- 관측 신호 추가·제거, 최근 512개 확정 시각, 과거 파형 커서와 현재 시각의 구분.

## 모델·시간 의미론

Clock: 출력 핀 하나, 속성 clock={period,duty,initial}. period는 2~1000000 정수 µs,
duty는 1~99 정수 %, initial은 0/1. 기본 10 µs·50%·0이다.
내부 시각은 0.01 µs 단위 정수이므로 주기×듀티 계산에 누적 부동소수 오차가 없다.
초기 레벨이 0이면 첫 상승엣지는 low 구간 후, 1이면 첫 하강엣지는 high 구간 후 발생한다.
초기 레벨 설정 자체는 엣지가 아니다.

DFF: 핀 순서 D(in,index0), CLK(in,index1), Q(out,index2).
핀 좌표는 회전 전 (-40,-10), (-40,10), (40,0).
dff={edge,initial}; edge는 rising/falling, initial은 0/1/X.
기본 상승엣지·X. 하강엣지는 CLK 반전 버블로도 표시한다.
비동기 Set/Reset/Enable·보수 출력·추가 FF 변형은 이번 범위에 포함하지 않는다.

같은 timestamp의 모든 Clock 소스 변화를 먼저 적용하고 조합논리를 계산한다.
모든 DFF는 그 결과와 이전 Q를 읽어 다음 Q를 결정한 뒤 동시에 갱신한다.
DFF→DFF 체인은 부품 등록 순서와 무관하게 이전 Q를 전달한다.
Q가 다른 DFF의 클럭에 연결되면 같은 시각의 delta round로 안정화한다.
시뮬레이션은 이상적 논리 시간이며 실제 지연·setup/hold·메타안정성을 재현하지 않는다.

확정 0→1 또는 1→0만 지정 엣지로 샘플링한다.
X/Z를 포함해 지정 엣지가 일어났을 가능성이 있는 변화는 Q=X로 보수 처리한다.
같은 X/Z 레벨의 유지에는 새 엣지를 만들지 않는다.
샘플링한 D가 X/Z이면 Q=X이다. 일반 게이트의 기존 Z→X·지배값 규칙을 유지한다.
Input을 CLK에 직접 연결한 수동 엣지도 일시정지 중 처리할 수 있다.

## 실행·편집 경계

- 일시정지: 현재 시간·Q·파형 유지. 재실행은 현재 시점부터 진행.
- 초기화: t=0, Clock 초기 위상·DFF 초기 Q 복원, 파형 기록 초기화. 외부 Input 값과 관측 목록 유지.
  실행 세션 초기화이며 부품의 Reset 핀을 누르는 기능이 아니다.
- 시뮬레이션 표시를 끄면 일시정지하며 시간·Q를 보존한다. 다시 켜면 같은 세션을 표시한다.
- 실행 중 구조 편집과 수동 Input 변경을 잠근다. 선택·보기 이동·줌·관측은 허용.
- 확정 회로 객체가 바뀌면(속성·경로·위치 편집과 Undo/Redo 포함) 실행을 정지하고 새 세션을 t=0으로 초기화.
  미확정 초안·취소·선택·보기 이동은 시간 상태를 초기화하지 않는다.
- 입력값·시간·Q·파형·관측은 Editor history에 기록하지 않는다. 입력 변화는 현재 시각에서 안정화 후 기록.
- 숨겨진 탭에서는 실행을 일시정지한다. 화면 재생 속도 1/2/5/10 시각/초는 벽시계 표시 속도이며 Clock 주기와 독립.
- 예약된 Clock 이벤트가 없으면 실행/Step을 비활성화하고 이유 표시. 수동 CLK 입력은 가능.

다음 이벤트는 다음 timestamp의 모든 소스 이벤트와 delta 안정화까지 한 번 처리한다.
다음 상승엣지는 선택한 Clock의 다음 0→1까지 다른 Clock 이벤트도 빠짐없이 처리한다.
한 주기는 현재 시각에서 선택 Clock 주기만큼 진행하며 중간 이벤트도 모두 처리한다.
현재 모델에서 자동 예약 이벤트는 Clock 소스뿐이다. 일반 입력 이벤트 시간표·지연 이벤트는 미지원.

## 안전 한도와 파형

- 같은 시각 안정화 최대 64 round.
- 한 Step의 중간 timestamp 최대 2048개. 초과 시 해당 Step 전 시간·Q·입력·스케줄·파형으로 원자적 복구하고
  SEQUENTIAL_LIMIT 진단 후 정지. 초기화로 재개. 정수 시간 정밀도 한도도 검사한다.
- INVALID_CIRCUIT는 기존 계산 중단/오류 표시를 유지한다. X/Z나 구동 충돌을 유효한 Q로 위장하지 않는다.
- 관측 최대 32개(핀 또는 net), 기록 최대 512시각. 오래된 기록이 제거됐음을 표시한다.
  기본 관측은 Input/Clock/DFF/Output의 출력 또는 관측 핀이다.
- 같은 timestamp의 기록은 안정화된 최종값으로 갱신한다. 신호를 나중에 추가해도 이전 값을 만들어 넣지 않는다.
- 파형 커서는 기록값만 바꾸며 현재 시뮬레이션 시각·Q·도면·history를 바꾸지 않는다.
- 임의 파형 줌/패닝, 두 커서 시간차 측정, 되감기, 내보내기는 후속이다.

## 저장·복구 브랜치와 합칠 때

이 브랜치 기준에는 회로 파일 저장 기능이 없다.
저장·복구 브랜치와 통합할 때 circuit kind 검증에 Clock/DFF를 추가하고 clock/dff 속성을 보존·검증해야 한다.
기존 v1이 두 kind를 거부하는 경우 형식 버전/호환 정책을 명시적으로 결정한다.
시간·현재 Q·이벤트 큐·파형은 문서 속성으로 저장하지 않는다. Clock 설정과 DFF 초기 Q는 설계 속성이다.
문서 교체는 회로 객체 교체와 함께 새 시간 세션을 생성하고 Input 초기화 정책은 저장 브랜치의 문서 교체 규칙을 따른다.
