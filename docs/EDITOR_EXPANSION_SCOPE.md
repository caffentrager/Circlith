# 에디터 확장 작업 범위

작성일: 2026-10-16

기준 커밋: `51552a7`

상태: 사용자와 정리한 통합 작업 범위. 확장 기능은 미구현이며, QA 버그 수정은 별도로 진행한다. 사용자의 2026-10-16 지시에 따라 요청·추천·검토한 기능을 즉시 구현 단계와 후속 단계로 모두 기록한다.

## 목적과 기준

로컬에서 안정적으로 사용할 수 있는 에디터를 완성한다. 기존 선택·배선·이동·회전·삭제를 유지하면서 아래 기능을 단계적으로 확장한다. 구현 기준은 `CIRCLITH_MASTER_SPEC.md`이며, 구현 단계에서 해당 명세의 상태·관련 결정을 함께 갱신한다. 이 계획을 기록하는 커밋은 기능 구현, 브랜치 병합 또는 배포 정책 변경을 포함하지 않는다.

## 공통 동작과 검증 기준

- 회로 수정은 기존 Command → Editor 경로를 사용한다. Editor의 상태·명령 책임을 입력 해석 계층으로 옮기지 않는다.
- 회로 편집 작업 하나를 Undo 한 번으로 되돌리고 Redo로 정확히 복원한다. 실패·취소는 회로와 기존 기록을 보존한다.
- 확정 전 미리보기는 회로 저장에서 제외하며 Esc로 취소한다. 텍스트 편집·IME 중에는 도면 명령이 입력을 가로채지 않는다.
- 설정 변경만으로 기존 회로의 위치·경로·전기적 연결을 바꾸지 않는다. 스냅 후보 강조와 실제 연결 확정을 분리한다.
- 입력 프리셋은 물리 입력을 명령에 매핑한다. 프리셋별로 Editor 의미론을 바꾸지 않는다.
- 회로 파일, 브라우저 복구 데이터, 사용자 설정, 화면 상태를 구분한다. 임시저장 성공과 명시적 파일 저장 성공을 구분한다.
- 파일 전체 검증이 성공한 뒤에만 현재 회로를 교체한다. 저장 실패·용량 초과·손상은 안내하고 파일 저장 경로를 제공한다.
- 미구현 명령은 unavailable로 유지한다. 색상만으로 연결 여부나 오류 상태를 구분하지 않는다.
- 단위 테스트로 연결·ID·저장 왕복·Undo 불변식을 확인하고, 브라우저 테스트로 실제 입력·복구·포커스·취소를 확인한다.

## 권장 구현 순서

0. Claude QA 등에서 보고된 버그를 재현·수정하고 회귀 검증한다. 사용자 보류 항목은 따로 명시하며 확장 기능 구현과 혼합하지 않는다.
1. 임시저장·복구와 파일 저장·열기·새 도면
2. 복사·잘라내기·붙여넣기·Duplicate, 프로퍼티즈, 정렬·균등분배·방향키 이동, 배선 끝점 재연결
3. 하이어라키·우클릭 메뉴, Recent·Favorites·Command Palette
4. 줌·그리드·스냅·교차점·색상 설정과 정렬 가이드
5. 연결 상태 진단과 패널·레이아웃 마무리

각 단계는 독립적으로 검증하고 커밋한다. 구체적인 줌 범위, 그리드 허용 간격, 속성 항목 등 미정인 세부 동작은 구현 전에 정의한다. 기존 Master Spec의 클립보드·입력 의미론을 유지한다.

## 추가 제안 검토 반영 — 2026-10-16

사용자가 검토 의견을 수용하여 Duplicate, 방향키 이동, 정렬·균등분배, Recent·Favorites, Command Palette를 이번 계획에 추가한다. 기능 구현은 아직 시작하지 않는다.

- Duplicate 기본키는 Master Spec의 `Shift+D`를 따른다. 복사 데이터·새 ID 생성·붙여넣기 미리보기 처리를 재사용한다. 반복 복제의 변위 재사용은 실험 항목을 유지한다.
- 복사한 부품 사이의 내부 배선을 포함한다. 명시적으로 선택한 외부 배선도 포함할 수 있으며, 복사하지 않은 외부 회로에 붙었던 끝점은 복제본에서 dangling으로 변환한다. Cut은 클립보드 기록 성공 후에만 삭제한다.
- 정렬·균등분배는 부품마다 이동량이 다르므로 기존의 동일 변위 일괄 이동 함수를 그대로 반복 적용하는 것으로 완료 처리하지 않는다. 기준 경계·분배 방식·그리드 오차 정책을 정의하고, 최종 결과 전체의 연결 보존·경로 유효성을 검증한 뒤 원자적으로 확정한다.
- 방향키 이동의 작은·큰 이동량과 연속 입력의 Undo 묶음은 구현 전에 정의한다. 텍스트·IME·모달 입력과 충돌하지 않게 한다.
- Command Palette 호출키는 Master Spec과 입력 프리셋의 충돌을 확인한 뒤 정한다. 명령 목록에 있다는 이유로 미구현 명령을 활성화하지 않는다.

## 통합 로드맵의 후속 단계

시뮬레이션, 실제 서브회로 계층, 실시간 협업은 후속 범위다. 하이어라키 트리는 현재 도면 탐색 기능이며 서브회로 정의·인스턴스·포트 기능을 뜻하지 않는다.

사용자의 통합 반영 지시에 따라 아래 항목도 전체 계획에 포함한다. 이번 에디터 필수 단계의 완료 조건에 모두 묶지 않고, 선행 조건을 갖춘 후 별도 구현한다. 검토한 후보·실험 상태가 자동으로 구현 확정을 뜻하지는 않는다.

| 항목 | 선행 조건·동작 정책 |
|---|---|
| Object/Selection Lock | 잠금의 이동·회전·정렬·삭제·속성 수정 범위, 잠금 중 배선 연결과 일괄 잠금 해제 규칙 정의 |
| Component Replace/Swap | 핀 수뿐 아니라 역할·대응 관계 호환 검사, 비호환 교체의 영향 미리보기·연결 처리·Undo. 미지원 부품을 교체 대상으로 만들지 않음 |
| Selection Cycling | 밀집한 부품·배선·접속점 후보 탐색·강조, 단축키·포커스 충돌 방지. 현재 배선 동률 선택 창과 구분하여 일반 객체로 확장 |
| Local Version/Recovery History | 기본 임시저장 이후 버전 보존·용량·정리·복원·현재 문서 보호 정책 정의 |
| Mini-map | 큰 도면에서의 필요성과 렌더링 비용 확인 후 탐색 기능으로 구현 검토 |
| 선택적 Google Drive 저장 | 로컬 저장·문서 형식 안정화 후 인증·권한·만료·오프라인·충돌 처리. 별도 서버 운영 없이 Pages 유지 |

- Quick Place는 `EXPERIMENTAL`을 유지한다. 검색·Recent·Favorites·Duplicate를 먼저 완성하고 반복 배치에서 필요성이 확인되면 검토한다.
- Logic ERC는 현재 계획의 미연결 진단 이후 별도 확장으로 둔다. 다중 드라이버 등 구조 경고와 실제 신호 값 충돌을 구분하며, 출력 핀끼리 연결됐다는 이유만으로 편집을 금지하지 않는다. 부품 이름 `Output`과 핀 방향을 혼동하지 않는다.
- Text/Annotation, Net Label, Mirror는 후속 범위로 둔다. Net Label은 이름의 연결 범위·변경·삭제·파일 형식 규칙이 필요한 전기적 기능이며, Mirror도 핀 변환·배선·저장 규칙을 먼저 정의해야 한다.
- 이번 에디터 범위를 완료하면 기능을 계속 늘리기보다 조합논리 시뮬레이션 MVP를 다음 큰 단계로 삼는 것을 권장한다. 착수 전 0/1/X/Z 진리표·다중 드라이버·피드백 안정성 규칙을 확정한다. 시간 시뮬레이션·Clock·D-FF·파형은 그 이후 범위다.

## QA 후 남은 정책 확인

- 두 부품만 삭제하고 사이 배선을 선택하지 않았을 때 선을 남길지 함께 지울지는 사용자 설명 요청 상태다. 현재 미연결 선을 남기는 동작을 임의 변경하지 않는다.
- 꺾임점 삭제 시 핀 출입 방향과 주변 꺾임 정리 허용 범위는 후속 정책 확인 사항이다. 현재 끝점·연결·남은 고정 경유점을 보존하는 동작을 유지한다.
- 낮은 줌에서 몸체 클릭과 넓은 핀 포획 범위의 우선순위 수정은 사용자가 **다른 버그부터 수정**하도록 보류했다. 관련 QA 테스트도 변경하지 않는다.

## Pages와 클라우드 저장 검토안

사용자는 별도 서버 운영 없이 GitHub Pages 기반으로 운영하기를 원한다. 공식 문서 조사 결과와 권장 구성을 [PAGES_DRIVE_STORAGE.md](PAGES_DRIVE_STORAGE.md)에 기록했다. 로그인 없이 로컬 편집·저장을 완성하고 선택적으로 Google Drive 연결을 추가하는 방안을 권장한다. 공급자 연동 구현은 아직 확정·착수하지 않았으며, 계정·클라우드 리소스 생성과 인증 연동은 이 기록 커밋에 포함하지 않는다.
