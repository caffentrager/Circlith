# Circlith 조작 명세 v0.2

> **보관 문서 / 구현 기준 아님.** 현재 설계와 구현은 [CIRCLITH_MASTER_SPEC.md](../CIRCLITH_MASTER_SPEC.md)를 우선한다. 아래 내용은 통합 이전의 제안·검토 이력이며, 서로 다른 기본값이나 후보는 현재 명세를 대체하지 않는다.

이 문서는 설계 제안이다. 수치와 기본값은 실제 사용자 검사 전의 가설이며 구현 또는 측정 결과가 아니다.

추천 단축키와 선정 이유는 [SHORTCUTS.md](SHORTCUTS.md)에 정리한다. 배선 꺾임은 Shift+Space, Tab은 기본 포커스 이동으로 변경했다.

## 상태와 명령 경계

기본 도구는 선택이다. 영속 도구는 선택·배선 두 개이며, 배치·이동·회전·영역 선택은 일시적인 제스처다. 입력 창과 모달에 포커스가 있으면 도면 단축키를 처리하지 않는다.

| 상태 | 시작 | 완료 | 취소 |
|---|---|---|---|
| 선택 대기 | V, 도구 버튼, 새 도면 | 대상 클릭 또는 제스처 시작 | Esc로 선택 해제 |
| 부품 배치 | 부품 검색 결과 선택 | 클릭으로 1개 배치, 기본 선택으로 복귀 | Esc로 미리보기 폐기 |
| 연속 배치 | Shift를 누른 채 배치 클릭 | 클릭마다 별도 배치 기록 | Esc로 종료, 기존 배치 유지 |
| 영역 선택 | 선택 도구에서 빈 공간 드래그 | 놓으면 대상 집합 확정 | Esc로 이전 선택 복원 |
| 부품 이동 | 선택 부품을 드래그 또는 M | 드래그 놓기 또는 키보드 이동의 클릭/Enter로 이동과 배선 경로를 함께 확정 | Esc로 원래 위치·경로 복원 |
| 배선 대기 | W 또는 도구 버튼 | 핀/배선 접속 위치 클릭으로 시작 | Esc로 선택 도구 복귀 |
| 배선 진행 | 시작 핀 또는 배선의 위치 클릭 | 대상 핀/배선 클릭으로 연결 확정 | Esc로 초안 전체 폐기, 배선 대기로 복귀 |
| 배선 선분 이동 | 선택한 배선의 선분 드래그 | 놓으면 경로 확정 | Esc로 원래 경로 복원 |
| 화면 이동 | Space+드래그, 휠 버튼 드래그 | 놓으면 이전 도구로 복귀 | Esc로 제스처 종료 |

Esc는 가장 가까운 진행 작업 하나만 취소한다. 도구 전환 또는 Undo 요청은 먼저 진행 중 미리보기를 폐기한다. Undo는 그 뒤 마지막 확정 작업을 복구한다. 미리보기 중 저장은 마지막 확정 회로를 저장하고 초안이 제외됐음을 상태줄에 알린다.

## 판정·스냅

- 미세 포인터의 초기 후보: 핀 반경 9 화면 px, 배선 거리 6 화면 px, 드래그 시작 거리 4 화면 px. 확대율과 무관한 화면 거리다.
- 배선 도구에서는 핀 → 접속점 → 선분 순으로 연결 후보를 찾는다. 선택 도구에서는 선택한 선분 핸들 → 부품 본체 → 배선 → 빈 공간 순이다. 핀에서 배선을 시작하려면 W를 사용한다.
- 가까운 후보가 여럿이면 거리와 명확한 강조로 결정한다. 중첩된 대상은 반복 클릭으로 후보를 순환하며 대상 이름을 표시한다.
- 그리드는 초기 10 도면 단위. 핀·접속점 스냅이 그리드보다 우선한다. Alt로 그리드 스냅만 일시 해제할 수 있다.
- 전기적 연결은 대상 핀/접속점이 강조된 상태에서 명시적으로 완료했을 때 만든다. 이동 중 핀과 선이 겹쳐도 새 연결을 만들지 않는다.

## 선택과 화면 이동

- 클릭은 기존 선택을 교체한다. Shift+클릭은 대상을 추가하거나 제외한다.
- 왼쪽→오른쪽 영역 선택은 완전히 포함된 부품·배선만, 오른쪽→왼쪽은 걸친 대상까지 선택한다. 상태줄에 ‘포함 선택’/‘교차 선택’을 표시하고 선택 후보를 미리 강조한다.
- Shift+영역 선택은 현재 선택에 후보를 추가한다. Ctrl+A는 도면의 모든 편집 대상을 선택한다. 입력 필드에서는 텍스트 선택이다.
- 이미 선택된 부품을 누르면 다중 선택을 유지한 채 이동한다. 선택하지 않은 부품을 드래그하면 먼저 해당 부품만 선택한다.
- 빈 공간 클릭은 선택을 해제한다. 빈 공간 드래그는 영역 선택이다.
- 휠은 커서 중심 확대/축소. 보기 맞춤은 Home. Space+드래그와 휠 버튼 드래그는 화면 이동이며 회로 Undo에 기록하지 않는다.

## 배치와 변환

- 검색은 이름과 기능 설명을 대상으로 한다. 결과에 심벌·간단한 설명·핀 정보를 제공한다.
- A로 부품 검색을 연다. 결과 선택 후 커서에 미리보기를 표시한다. R은 반시계 방향 90도 회전, Shift+R은 시계 방향. 배치 중에도 같은 키를 사용한다.
- 부품 이동 시 연결된 배선은 해당 핀을 따라가며 직각 경로를 미리 보여준다. 외부 끝점과 논리 연결을 유지하고 자동 단선·새 접속을 만들지 않는다.
- 연결을 유지하기 어려운 경로는 겹침 경고를 표시한다. 경고를 이유로 연결을 자동 삭제하지 않는다. 부품 겹침과 배선 교차는 허용하되 선택·접속을 혼동하지 않게 표시한다.
- 다중 회전은 표시된 선택 범위 중심을 기준으로 한다. 외부 연결을 유지한다. 대칭·정렬·간격 조정은 기본 편집 검증 이후의 확장 후보다.

## 배선

1. 시작 핀 또는 기존 선분 위치를 클릭한다. 기존 선분에서 시작하면 접속점 생성은 초안 완료 시 확정한다.
2. 커서를 따라 직각 배선 미리보기를 표시한다. 빈 공간 클릭은 경유점을 고정한다.
3. Shift+Space로 마지막 구간의 가로 우선/세로 우선을 전환한다. 도면 배선 초안 중에만 처리하고 상태줄에 안내한다. Tab/Shift+Tab은 기본 포커스 이동을 유지하며 이 경우 초안은 일시 유지한다.
4. Backspace로 마지막 고정 경유점을 제거한다. 시작점만 남았을 때 Backspace는 초안을 취소한다.
5. 강조된 대상 핀 또는 기존 선분을 클릭해 완료한다. 연결된 접속점에는 점을 표시한다.

- 빈 공간 더블클릭은 미연결 끝점을 만들고 경고를 표시한다. 첫 클릭의 경유점은 중복 저장하지 않는다. 주 완료 경로는 대상 클릭이다.
- 교차는 연결이 아니다. 교차점에 명시적으로 분기 완료하면 접속점을 만들고 관련 선분을 같은 노드에 연결한다.
- 자신의 시작점이나 이미 같은 네트에 속한 대상에 연결하려 하면 중복 연결 안내를 표시하고 초안을 유지한다. 조합회로 피드백은 진단 대상으로 별도 처리한다.
- 출력끼리의 연결은 허용하되 다중 드라이버 진단을 즉시 제공한다. 신호값이 충돌하면 X를 표시한다.
- 선택한 선분은 수직 방향으로 옮겨 직각 경로를 조정한다. 핀 끝점과 접속 노드는 고정한다. 새 접속은 만들지 않는다.

## 삭제·클립보드·Undo

- Delete는 선택 대상만 삭제한다. 부품에 연결된 외부 배선은 남기고 삭제된 핀 쪽 끝점을 미연결로 전환한다. 삭제 미리보기에서 영향을 강조한다. Undo는 부품·끝점·연결을 함께 복구한다.
- 배선 삭제는 해당 경로만 제거한다. 같은 접속점의 다른 가지는 유지한다. 불필요한 접속 노드 정리는 같은 작업에 포함한다.
- 복사는 선택 부품과 그 사이의 내부 배선을 포함한다. 명시적으로 선택한 배선도 포함한다. 선택하지 않은 외부 회로에 붙은 끝점은 복사본에서 미연결로 변환한다.
- 붙여넣기는 커서 위치에 그룹 미리보기를 보여준다. 클릭으로 확정하며 새 ID를 발급한다. Esc는 취소한다.
- 부품 이동, 회전, 선분 이동, 배선 완료, 삭제, 붙여넣기, 속성 확정은 각각 하나의 Undo다. 선택·뷰 이동·줌은 회로 기록에 넣지 않는다.
- Ctrl+Z / Ctrl+Shift+Z는 Undo/Redo. Ctrl+Y도 Redo 별칭으로 제공한다. 새 편집을 확정하면 Redo 분기를 폐기한다.
- 초기 제안은 최근 100개 작업과 메모리 제한을 함께 적용하는 것이다. 실제 한도는 회로 크기별 측정 후 확정한다.

## 시뮬레이션과 편집

- 첫 버전은 입력 전환 후 조합회로를 재계산한다. 입력 스위치는 본체 선택과 구분되는 명시적 토글 영역을 가진다.
- 0/1/X/Z를 텍스트와 선 스타일로 구분한다. X 진단은 원인 대상 선택과 보기 맞춤으로 이어진다.
- 이후 시간 시뮬레이션에서는 구조 편집을 확정하기 전에 실행을 정지한다. 새 구조로 계산 상태·시간·파형을 초기화하며 현재 입력값은 유효한 입력 ID에 한해 유지한다.
- 시작/정지와 입력 전환은 회로 구조 Undo에 넣지 않는다. Undo가 구조를 복구하면 실행을 멈추고 복구한 구조의 시뮬레이션을 초기화한다.
- Run은 현재 시점에서 재개, Reset은 t=0으로 초기화한다. 정확한 Step 이벤트·클록 정책은 시간 시뮬레이션 단계에서 별도 명세를 작성한다.

## 저장·복구와 접근성

- Ctrl+S는 명시적 파일 저장, Ctrl+O는 파일 열기. 변경이 있는 도면을 교체할 때만 저장·폐기·취소 선택을 제공한다.
- 자동 복구는 마지막 확정 편집 후 저장한다. 파일 저장 성공과 브라우저 자동 복구 상태를 별도 표시한다.
- 읽기·검증 실패 시 기존 회로를 유지하고 원인과 대상 필드를 알려준다. 부분적으로 현재 회로를 덮어쓰지 않는다.
- localStorage 등 저장소 실패는 조용히 무시하지 않는다. 상태줄 경고와 파일 저장 경로를 제공한다.
- 모든 주요 명령에 버튼·메뉴 접근을 제공한다. 포커스가 도면일 때만 V/W/R/Space 등의 키를 처리한다.
- Esc, 파일 창 취소, 포인터 캡처 상실·창 포커스 상실 시 편집 제스처는 롤백한다. 진행 초안을 자동 확정하지 않는다.
- Tab으로 앱 내부 포커스를 이동하는 것은 의도적 UI 탐색이다. 초안을 잠시 유지하되 입력 필드에서는 도면 단축키를 처리하지 않는다. 앱 창 비활성화와 구분한다.
- 좁은 화면에서는 패널을 접어 명시적 버튼으로 연다. 터치 편집과 완전한 키보드 회로 편집은 후속 명세 대상이며 현재 지원 완료로 주장하지 않는다.
